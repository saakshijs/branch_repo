# Quick Food Order App

A simple Python web application built with Flask for placing quick food orders.

## 🚀 Features

- Select your favorite food (Pizza, Burger, Dosa) from a dropdown menu.
- Instant order confirmation message upon submission.

## 🛠️ Prerequisites

- Python 3.x
- Flask

Install Flask using pip:
```bash
pip install flask
```

## ▶️ Getting Started

1. Run the Flask application:
   ```bash
   python app.py
   ```
2. Open your web browser and navigate to:
   ```
   http://127.0.0.1:5000/
   ```
